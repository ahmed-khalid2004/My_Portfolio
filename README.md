- 🎨 **Dark Professional Design** — Deep navy color scheme with blue accent tones
- 📱 **Fully Responsive** — Works perfectly on desktop, tablet, and mobile
- ⚡ **Pure Vanilla Stack** — Zero frameworks, zero dependencies — just HTML, CSS & JS

- 📊 **Animated Skill Bars** — Scroll-triggered progress bar animations

## 🚀 Deployment (GitHub Pages)

### Step 1 — Clone the repository
```bash
git clone https://github.com/ahmed-khalid2004/Portfolio_Website.git
cd Portfolio_Website
```

### Step 2 — Add your assets
Place your profile photo and CV in the correct folders:
```
Images/WhatsApp Image 2025-01-02 at 19.54.27_96a67c97.jpg
CV/Ahmed_Khaled_CV.pdf
```

### Step 3 — Set up Formspree (contact form)
1. Go to [formspree.io](https://formspree.io) and sign up for free
2. Create a new form with your email `engahmedkhalid3s@gmail.com`
3. Copy your unique endpoint (e.g. `https://formspree.io/f/xabcdefg`)
4. In `index.html`, replace the form action:
```html
<!-- Find this line: -->
<form ... action="https://formspree.io/f/engahmedkhalid3s@gmail.com" ...>

<!-- Replace with your actual Formspree endpoint: -->
<form ... action="https://formspree.io/f/YOUR_FORM_ID" ...>
```

### Step 4 — Push to GitHub
```bash
git add .
git commit -m "feat: add portfolio with assets"
git push origin main
```

### Step 5 — Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select `Deploy from a branch`
4. Set branch to `main` and folder to `/ (root)`
5. Click **Save**
6. Your site will be live at:
   ```
   https://ahmed-khalid2004.github.io/Portfolio_Website/
   ```

> ⏱️ GitHub Pages may take 1–2 minutes to go live after the first deploy.
